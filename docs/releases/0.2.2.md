# Local AI 0.2.2

[Русская версия](0.2.2.ru.md)

The installer now gives Codex and Claude shared instructions to minimize cloud file reading. Agents should delegate first reading and mechanical analysis to Local AI using file paths and a concise task, then use the bounded findings without routinely rereading the source in the cloud.

Direct cloud reads remain available for necessary verification, ambiguity resolution and exact fragments needed for safe edits. Governing instructions are read directly. If the cloud agent has already read or created the relevant content, it should skip a local call unless the expected reduction in remaining work outweighs the request and response overhead. Token comparisons must honestly account for already-seen and partially seen sources.

These instructions are applied when installing or reapplying the Codex or Claude instruction integration. A runtime-only update does not rewrite client instructions. Existing custom guidance outside the managed block is preserved.
