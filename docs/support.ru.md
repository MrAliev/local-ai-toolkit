# Как получить помощь

[English version](support.md)

[GitHub issues](https://github.com/MrAliev/local-ai-toolkit/issues) предназначены для
воспроизводимых ошибок и предложений. Сначала проверьте существующие issues.
Для вопроса по использованию укажите команду и ожидаемый результат; не публикуйте
исходники, учётные данные или полные журналы.

## Полезный диагностический отчёт

Укажите версию релиза, архитектуру Windows, клиент, точную команду, текст ошибки,
ожидаемое поведение и минимальное воспроизведение. Добавьте относящийся к проблеме вывод
`localai doctor`, `localai repo status --root <repository>` и `localai model status`
через установленный launcher. Скройте пути пользователей, имена репозиториев, секреты
и сведения о других проектах. Короткий фрагмент обычно полезнее полного лога.

## Типичные ситуации

| Симптом | Что проверить |
| --- | --- |
| Репозиторий не подключён | [Настройка](using-it-from-the-command-line.ru.md) — подключение явное |
| Индекс отстал или нет overlay | Статус и обновление для текущего worktree; не запускайте дублирующие сборки |
| Модель не помещается | [Политику размещения](installing.ru.md); не выгружайте модель другой сессии |
| Экономии нет или она неизвестна | [Сравнение токенов](token-comparison.ru.md), версию runtime и доказательства |
| Релиз не обнаружен | Публичный URL релиза, сеть и [инструкцию установки](installing.ru.md) |

При подозрении на уязвимость следуйте [политике безопасности](https://github.com/MrAliev/local-ai-toolkit/blob/main/SECURITY.ru.md).
Поддержка сообщества предоставляется по возможности, без гарантии времени ответа.
