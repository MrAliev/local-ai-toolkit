# Конфиденциальность

[English version](privacy.md)

Local AI по умолчанию выполняет модели через Ollama на Вашем компьютере. Локальные
инструменты возвращают результаты вызвавшему их клиенту, включая ответы модели и выбранные
фрагменты исходников. Облачный агент может включить эти результаты в запросы своему
облачному провайдеру. Локальное выполнение модели не гарантирует, что возвращённое содержимое
останется на этом компьютере: такую передачу определяют настройки и политика обработки
данных клиента.

Здесь перечислены соединения, которые сама Local AI устанавливает с другим компьютером:
что их запускает и что по ним уходит. Соединениями облачного клиента управляет сам клиент.

## Локальная обработка и хранение

- **Запросы к модели.** С моделями работает только брокер; по умолчанию он обращается к Ollama
  по адресу `http://127.0.0.1:11434/`, на этом компьютере. Брокер, который Вы сами запустили
  вручную с другим адресом, отправляет запросы к модели по этому адресу. Получив результаты,
  клиент может передать их дальше, как описано выше.
- **Индекс кода.** Он строится и хранится в `%LOCALAPPDATA%\LocalAi\repositories`.
- **Отчёты об использовании и телеметрия моделей.** Они пишутся в
  `%LOCALAPPDATA%\LocalAi\telemetry`, и читает их только `localai telemetry`. Телеметрия
  моделей не принимает ни одного поля, названного промптом, ответом, содержимым, изображением,
  путём или секретом. Ни то, ни другое никуда не отправляется.

## Соединения с другими компьютерами

| Что | Куда | Когда | Что уходит |
| --- | --- | --- | --- |
| Поиск и загрузка релиза | `github.com`, затем `api.github.com`, если первый ответ не назвал релиз | при открытии установщика, если Вы не указали ему папку; ещё раз перед установкой; при `localai update` | анонимные HTTPS-запросы к файлам релиза |
| Размеры моделей | `registry.ollama.ai` | когда установщик проверяет компьютер | имя и тег каждой модели, которую он может предложить |
| Проверка обновлений | `github.com` | **по умолчанию выключена**; после включения — примерно раз в день | по умолчанию анонимные запросы манифеста и подписи; отдельно выбранный режим GitHub CLI использует авторизованный аккаунт |
| Зависимости | источники `winget` и `npm` | только для зависимостей, которые Вы отметили в установщике | то, что отправляют `winget` и `npm` |
| Модели | реестр моделей, которым пользуется Ollama | когда Вы выбираете модели в установщике, запускаете `localai model pull` или одобряете инструмент `local_models_sync` | то, что отправляет Ollama |
| Доступ через GitHub CLI | `github.com`, от Вашего имени | в установщике нужен явный выбор/согласие; для проверки обновлений — отдельная явная настройка аутентификации через GitHub CLI | то, что отправляет `gh` |

Анонимная проверка не отправляет аутентификацию аккаунта или идентификатор использования Local AI.
Явный режим GitHub CLI использует авторизованный аккаунт GitHub. Оба режима не отправляют
файлы проектов или отчёты об использовании Local AI. Проверка читает манифест и подпись,
но сама не скачивает пакет релиза и не устанавливает обновление.

## Что Вы можете сделать

- Включить или выключить проверку обновлений в установщике или командами
  `localai policy set --update-check on` и `--update-check off`.
- Ставить из папки релиза вместо GitHub: тогда установщик читает релиз из этой папки.
- Пропустить в установщике зависимости и модели и поставить их самостоятельно.
- Удалить устаревшие локальные данные командой `localai prune`; ключ `--dry-run` показывает
  результат применения правил хранения без удаления. Сохраняются действующие индексы активных
  репозиториев, а также отчёты об использовании и телеметрия в пределах срока хранения.
  Чтобы удалить и сохраняемые данные, откройте мастер удаления Local AI через «Приложения и
  возможности» и выберите нужные категории данных.

## Сайт документации

Интерактивная главная страница считает в браузере без аналитики и вызовов моделей.
Страницы справочника загружают Mermaid 11.12.1 с jsDelivr для схем; CDN получает обычный
веб-запрос, включая IP-адрес и метаданные браузера. Сайт и Wiki размещены GitHub по его
политике конфиденциальности. Эти соединения сайта отделены от установленного runtime.
