# Проверка PDF-парсера и OCR

[English version](README.md). Задача [#625](https://github.com/MrAliev/local-ai-toolkit/issues/625).

Корпус от 22 сентября 2026 года отдельно измеряет извлечение текстового слоя и
преобразование страниц в изображения через код продукта. Результаты поддерживают
сохранение OCR по умолчанию: наличие текста в PDF ещё не означает, что он совпадает
с видимым содержимым. Автоматический переход на текстовый слой не добавлен.

## Воспроизведение в Windows

Нужны .NET 10, Python 3, Segoe UI; для необязательной проверки OCR — установленный
брокер LocalAi и доступные OCR-модели. Из корня репозитория:

```powershell
dotnet build scripts/quality/pdf/PdfProbe.csproj --configuration Release
$pdfRun = Join-Path $env:TEMP ("LocalAi-pdf-" + [Guid]::NewGuid().ToString("N"))
python scripts/quality/pdf/run_probe.py $pdfRun
python scripts/quality/pdf/live_ocr.py $pdfRun
python scripts/quality/pdf/export_evidence.py $pdfRun scripts/quality/pdf/evidence --label new-run
```

Папка результатов должна быть новой и находиться вне репозитория. Экспорт не
перезаписывает существующие материалы. Нативная проверка не вызывает модели.
Режим raster использует настоящий `LocalTasks.ReadImageAsync`, заменяя только клиент
модели сборщиком изображений; его условный ответ не является результатом OCR.
Живая проверка обращается к установленному MCP-серверу через общий брокер и соблюдает
политику размещения моделей. Текущая метка provenance относится к установленной RC22;
при проверке другой версии её нужно обновить. Замеры установленного релиза и сборки
из исходников нельзя выдавать за замеры одного бинарного файла.

Каждый из 13 искусственных PDF проверяется в отдельном процессе в режимах text и
raster, по три повтора. Родитель завершает процесс через 10 секунд. Диагностические
ограничения также составляют 1000 страниц и миллион символов на страницу; это не новые
лимиты продукта. Пиковая память измеряется, но не ограничивается. Файловый кеш ОС
может быть прогрет. PDF, исходные stdout/stderr, хеши и ответы MCP остаются во внешней
папке. Для воспроизведения используйте тот же шрифт и платформу и сравнивайте хеши.

## Результаты нативной проверки

[Все повторы, хеши PDF, исходников и бинарных файлов, сведения о машине](evidence/2026-09-22-native.json).
Исходники продукта: `8e4ffb06bca2402160a5a1c0f1d9e17ae69bfe16`; новый диагностический
код отдельно идентифицирован SHA-256. Зависимости: PDFtoImage 5.4.0, PDFium 152.0.7961,
SkiaSharp 4.150.1. Завершились все 78 процессов: 48 успешных чтений и 30 отказов
парсера, без тайм-аутов и аварийных завершений. Завершившийся процесс может сообщить
об отклонённом документе. Максимальный наблюдавшийся рабочий набор — 66,29 МиБ.

Сравнение нормализует пробелы, сохраняя символы, порядок и повторяющиеся строки.
Полное время процесса, загрузки/чтения нативного текста и преобразования в растр
хранятся отдельно. Например, медианы полного времени для английского PDF —
75,772 мс (текст) и 129,099 мс (растр). Это время парсера, а не OCR или экономия
облачных токенов. Тесты не проверяют скорость машины.

Все полученные растры укладываются в 4 миллиона пикселей и 4096 пикселей по каждой
стороне, включая огромные и очень широкие страницы. Ограничение входа в 256 МиБ и
последовательная обработка сохранены. Существующие тесты PDF проверяют ограничения;
этот небольшой корпус не нагружает все границы выделения памяти и числа страниц.

### Решение по текстовому слою

Извлечение быстрое на простых примерах, но не заменяет OCR для сканов, смешанных
документов и невидимого текста. Символьный API PDFium предоставляет текстовые объекты,
не гарантируя их видимость. API также описывает включение символов за пределами
crop box ([официальный заголовок](https://pdfium.googlesource.com/pdfium/+/refs/heads/main/public/fpdf_text.h)).
Проверка использует `FPDFText_GetUnicode` вместо буфера UCS-2 и учитывает символы без
соответствия. Для будущего перехода на текстовый слой нужны независимо проверенные
критерии видимости, порядка чтения и возврата к OCR.

### Решение по нативному парсеру

Пять повреждённых PDF отклонены, один восстановлен. Зависание нативного кода на этом
корпусе не воспроизведено. В этом изменении сохраняются последовательная обработка
и ограничения файла/растра. Тайм-аут управляемого ожидания не останавливает зависший
нативный код: жёсткое ограничение времени или памяти потребует отдельного процесса
и протокола завершения/восстановления. Тайм-аут диагностического процесса не является
реализованной защитой продукта. Корпус не доказывает безопасность произвольных
враждебных PDF и не позволяет убрать существующие ограничения.

## Живой OCR и покрытие критериев приёмки

[Результаты установленной RC22 и метаданные использования](evidence/2026-09-22-ocr.json).
Три случая (английский текст, кириллица, английский скан), по одному проверенному
проходу, совпали с эталоном после нормализации пробелов; CER равен нулю. Повторы строк
сохранены. Модели: `glm-ocr:bf16 [offload_unknown]` и `qwen3-vl:8b-instruct-q8_0`.
Время по данным брокера: 28,350; 25,658; 25,746 с. Идентичность процесса и хеш сборки
брокера не менялись. `HeartbeatAtUtc` обновляется при работе и исключён из сравнения.

`sourceContext=AlreadyPresent` отражает известное заранее содержимое эталонов.
Условные оценки INPUT/OUTPUT: −1779/−47, −1812/−50 и −1791/−47 токенов.
Это не расход аккаунта и не положительная экономия; время и память измерены отдельно.
Ответы модели — данные, а не инструкции. Три искусственных документа не определяют
общее качество OCR; установленная RC22 не проверяет новый код контрольных точек.

Этот код проверяется отдельно тестами исходников из
[#690](https://github.com/MrAliev/local-ai-toolkit/pull/690),
[#691](https://github.com/MrAliev/local-ai-toolkit/pull/691) и
[#692](https://github.com/MrAliev/local-ai-toolkit/pull/692): выбор и нумерация страниц,
настоящий рендеринг PDF, Unicode, полная атомарная запись, защита жёстких ссылок,
отказ при изменении источника/маршрута/обработчика, возобновление прерванного и готового
сеанса, повреждённые/пропавшие записи, исключительное владение и повтор записи без
повторного вызова модели. Отмена проверяется управляемыми событиями, а не скоростью.
