# Первый репозиторий

[English version](Getting-started.md) · [Главная](Home.ru.md)

## Установить или обновить

При первой установке следуйте [руководству по установке](../installing.ru.md). Проверьте пакет по примечаниям к релизу и выберите зависимости и модели. Если LocalAI уже установлен, воспользуйтесь [руководством по обновлению](../updating-and-removing.ru.md). По умолчанию выбранная модель должна целиком помещаться в видеопамяти (VRAM).

## Подключить репозиторий и выполнить первый поиск

Откройте PowerShell и замените `C:\work\myapp` путём к рабочему дереву Git, которое хотите проиндексировать. Функция `lai` вызывает установленную программу запуска и доступна в текущем сеансе PowerShell.

```powershell
function lai { & "$env:LOCALAPPDATA\LocalAi\bin\launcher\localai-launcher.exe" run @args }
$repo = "C:\work\myapp"
lai localai repo status --root $repo
```

Если команда вернула `NOT_CONFIGURED`, запустите первичную индексацию. Каждый репозиторий подключается отдельно.

```powershell
lai localai sync --root $repo
```

Если синхронизация уже идёт, выполните `lai localai repo status --root $repo --follow` в другом сеансе PowerShell, где заданы те же `lai` и `$repo`. Следите за этапом и счётчиками.

После завершения сборки проверьте состояние индекса и выполните поиск из рабочего дерева. Замените пример запроса вопросом о своём коде.

```powershell
Set-Location -LiteralPath $repo
lai codesearch status --root $repo
lai codesearch search --query "где планируются фоновые задания" --top 3
```

Поиск выдаёт до трёх подходящих результатов в порядке релевантности, с путями к файлам и номерами строк. Если совпадений нет, попробуйте известное имя символа или функции.

### Поддерживать индекс в актуальном состоянии

Обновляйте индекс после сохранения правок, слияния или смены ветки. Клиенты MCP могут проверить `index_status` и при необходимости запустить `index_refresh`. Если нужно автоматически обновлять индекс после событий Git, например коммита или переключения ветки, установите хуки отдельной командой.

```powershell
lai localai hooks install --root $repo
```

Все параметры перечислены в [руководстве по командной строке](../using-it-from-the-command-line.ru.md) и в установленном навыке LocalAI.

## Разобраться с очередью или ошибкой

Проверьте идентификатор операции, этап и счётчики через `repo status --follow`. По умолчанию синхронизация обрабатывает выбранное рабочее дерево. Параметр `--all-worktrees` включает остальные. Предварительная оценка охватывает весь запланированный объём. Число фрагментов, скорость и оставшееся время показываются для текущего прохода, если эти данные доступны.

Чтобы запросить отмену, выполните `lai localai sync cancel --root $repo --operation <GUID>` с идентификатором операции, показанным при запуске. Затем проверьте итоговый статус. Если клиент перестал ждать из-за тайм-аута, операция может продолжаться.

При обращении за помощью укажите точный текст ошибки и текущий статус. Перед изменением настроек общего брокера проверьте, используют ли его другие проекты. См. [порядок диагностики](../support.ru.md).
