# Local AI 0.2.3

[Русская версия](0.2.3.ru.md)

This maintenance release improves shared updates, compiler-log verification and the explanation of token estimates.

## Changes

- Updates wait for active broker jobs to finish and pause new admissions during activation. CLI updates hand off to the launcher after the calling process exits, avoiding a conflict with its own version lease.
- Clients recover when the broker restarts while they are waiting for a queued or running job.
- Compiler-log reports use deterministic source evidence: diagnostic-line occurrences, counts by diagnostic code, source locations and a source hash. Repeated diagnostics in the original log remain counted; overlapping fragments do not multiply them. Model claims that disagree with this evidence are rejected, and MSBuild summary totals are reported separately.
- Token estimates compare the text visible to the cloud client with the estimated alternative workload, rather than counting the entire MCP transport envelope. These figures are approximate comparisons, not measured provider billing.
- Documentation baseline operations reject symbolic links, junctions and other reparse points before reading or writing. The standard build also uses the patched System.Security.Cryptography.Pkcs 8.0.2 dependency.
- English and Russian documentation clarify the local/cloud data boundary, retention behavior and installation from published releases. Windows test cleanup and SCIP probe failure diagnostics are more reliable.

## Upgrading

Download `LocalAi.Installer.exe` from the GitHub release. Keep the installer, `localai-package.zip`, `release-manifest.json` and `release-manifest.sig` from the same version together when installing offline.

The release uses the existing manifest-signing trust key. It does not require key rotation or a forced reindex. Other projects and sessions can continue using the shared runtime; activation drains active jobs before switching versions.

## Verification

Before preparing this release, the Release build completed with no warnings or errors. The complete local suite ran 5,937 tests: 5,920 passed, 17 skipped and none failed. Environment-dependent SCIP and symbolic-link checks account for the local skips; the GitHub workflow also validates the release commit in its CI environment.

The release helper requires a successful Build and test workflow for the exact release commit, then builds, signs and verifies the package before publishing the four assets. The manifest uses an ECDSA P-256 signature; this release does not claim Windows Authenticode signing of the installer.

The intermittent five-second SCIP probe failure tracked in [#843](https://github.com/MrAliev/local-ai-toolkit/issues/843) has additional diagnostics and independent per-tool checks. Its historical cause remains unconfirmed; this release does not claim to have fixed that root cause.
