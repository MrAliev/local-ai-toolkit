# Local AI 0.2.1

[Русская версия](0.2.1.ru.md)

Indexing now reports every phase, including preparation, project analysis, embedding, saving and activation. A status heartbeat appears every 15 seconds even when counters have not changed. Where available, it includes completed items, totals, rate and remaining time; unknown totals are stated explicitly. A failed embedding batch lowers the ceiling for the rest of that build instead of repeatedly trying the same failing size.

Usage messages now show one approximate number of cloud tokens saved. Zero savings, additional token usage and unavailable estimates have separate explanations. This is a comparison with reading source through cloud tools, not account billing. Detailed machine-readable usage fields remain available.

## Upgrading

The release signing key has been replaced after recovery of the publishing Windows environment. Install using the new LocalAi.Installer.exe attached to this release and select the release folder containing release-manifest.json, release-manifest.sig and localai-package.zip. Older installers trust the previous key and cannot verify this release. Keep the four downloaded files together. The new manifest signature and package hashes are checked during installation. The package does not require an Authenticode signature.

The working signing key is protected by Windows DPAPI. Its password-protected backup was restored and verified locally; no private key or password is included in this repository or release.
