# Как внести вклад

[English version](CONTRIBUTING.md)

Спасибо, что помогаете. Здесь коротко о том, как работа попадает в `main`.

## Сборка и тесты

Нужны Windows x64 и тот .NET SDK, который указан в `global.json`. Сборка и тесты никогда не
запускают Ollama, поэтому видеокарта не нужна.

```powershell
dotnet build LocalAi.slnx --configuration Release
dotnet test LocalAi.slnx --configuration Release --max-parallel-test-modules 1 --timeout 20m
```

Прогоните весь набор тестов до того, как открыть pull request, и укажите его итоги в описании.
Остальное — в разделе [«Собрать и проверить»](docs/building-and-testing.ru.md).

## Одна тема на pull request

- Ветка — от `main`, одна тема на ветку. Имя ветки начинается с вида работы, дальше — о чём
  она: `fix/`, `feature/`, `test/`, `docs/`, `refactor/` или `chore/`, например
  `fix/version-line-holds`.
- Сначала падающий тест, и он должен падать по той причине, которую Вы ожидаете. Потом код,
  с которым он проходит.
- Тест никогда не проверяет, насколько быстра машина: ждите наступления условия, а не
  истечения срока.
- Сообщения коммитов, pull request и issue пишутся по-английски.

## Текст, который печатает продукт

- Всё, что печатает программа, следует языку Windows читателя: по умолчанию английский, на
  русской системе — русский. Строки лежат парами `.resx` в `Resources/` той сборки, которая их
  печатает, и тест не пропускает язык, в котором есть только часть ключей.
- Исключение — установщик: оба языка стоят рядом в одном вызове
  `InstallerCulture.Pick(english, russian)`.
- Никогда не переводятся: команды, имена опций, идентификаторы, статус-токены, пути и
  атрибуты MCP `[Description]`. Числа, длительности и даты не зависят от языка.

## Документация

- Документация — это `README.md` и `README.ru.md`. Меняйте их вместе: предложение, которое
  перестало быть правдой, — это дефект.
- Страницы в `docs/`, которые заканчиваются комментарием `Generated from the README`, строятся
  из README. Не правьте их: правьте README, а затем пересоберите страницы:

  ```powershell
  $env:LOCALAI_WRITE_DOCUMENTATION_SITE = '1'
  dotnet test tests/LocalAi.Installer.Core.Tests/LocalAi.Installer.Core.Tests.csproj --configuration Release
  ```

- У каждого другого документа рядом лежит перевод, `name.md` и `name.ru.md`, и каждый
  ссылается на другой. Тест проверяет пары, ссылки и то, что ни одна ссылка не ведёт в пустоту.
