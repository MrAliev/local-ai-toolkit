# История изменений

[English version](CHANGELOG.md)

Опубликованные версии, файлы и полные заметки находятся в
[GitHub Releases](https://github.com/MrAliev/local-ai-toolkit/releases).
Release notes описывают поставляемые программы; в `main` могут быть более новые изменения.

## Ещё не выпущено

- Публичный портал документации, двуязычные исходники Wiki и инструкция публикации.
- Документы об управлении сообществом, поддержке и правилах поведения.
- Уточнение оценки токенов по необходимому контексту запроса и явного доступа через GitHub CLI.
- Основа CI для неподписанных кандидатов; одобрение SignPath, реальная политика сертификата
  и фактический Authenticode-релиз остаются в
  [#210](https://github.com/MrAliev/local-ai-toolkit/issues/210).

Прежние изменения записаны в [руководствах релизов](docs/releases/0.2.3.ru.md)
и GitHub Releases. Невыпущенная документация не доказывает наличие поведения
в уже установленном runtime.
