# Local AI 0.2.4

[Русская версия](0.2.4.ru.md)

## Changes

- Local-model usage notices estimate the full operation input minus the complete context returned to the cloud agent. CLI JSON uses the same estimate, including negative and zero results; unavailable evidence remains explicit. Historical usage records keep their original meaning. (#905)
- Windows broker launches preserve argument boundaries. (#884)
- Compiler-log processing can recover malformed compiler inventories while retaining source validation. (#864)
- Update checks support explicitly authenticated access to private GitHub releases. (#863)
- GitHub release metadata is isolated for each resolution. (#903)
- Command execution boundaries have been hardened. (#894)

## Updating

Run `lai localai update --wait` or use the installer from this release. The update verifies the signed release manifest and package before activation. Existing model selections do not need to change.

The token figures are hypothetical estimates of cloud context, not provider billing or proof of answer quality. Missing source evidence and failed delivery do not receive invented savings.
