# Общие ресурсы документации — часть #623

[English version](README.md)

База: `2e27375de42a7a6466b8e6ad128db75faac3b532`. Два HTML-шрифта встроены как data URL
в один CSS, названный по SHA-256, общий для всех артефактов и пакетов репозитория.
Пакеты уже используют общие артефакты; шрифты также общие. Apply сохраняет относительную
структуру в `docs/generated/_assets`. Автономный режим встраивает оба шрифта, диаграмму
и лицензии в страницу. Для перехода на другой язык нужна соседняя страница.
Публичный renderer возвращает автономный HTML.

## Сохранённые измерения

Стенд создаёт 1, 5 и 12 синтетических типов с детерминированным двуязычным текстом,
затем дважды меняет только метку снимка. Каждая версия применяется в отдельный тестовый
worktree. Broker, модель, подготовка исходников/индекса, сеть и установленный рантайм
не используются. Измеряется размер хранения, а не качество текста, задержка или экономия
облачных токенов. Входы одинаковы; хеши исходников и все строки сохранены
в [evidence](evidence/comparison.json).

| Типы / сохранённые версии | До, байт | Общие ресурсы, байт | Автономный HTML, байт |
| --- | ---: | ---: | ---: |
| 1 / 1 | 3 128 910 | 1 686 586 | 3 462 180 |
| 5 / 1 | 15 634 568 | 2 650 976 | 17 299 982 |
| 12 / 1 | 37 523 634 | 4 342 821 | 41 521 948 |
| 12 / 3 | 112 525 864 | 10 097 441 | 124 520 806 |

Это сумма логических длин файлов хранилища документации, включая кеш текста, метаданные
артефактов, страницы обзора, указатели и базовые хеши apply. Размер кластеров диска не
учитывается. Поля длительности в манифестах могут менять размер на несколько байт.
Общий CSS занимает **1 442 848 байт** во всех строках общего режима. Первое применение 12 типов
занимает **4 289 082 байта** вместо **37 471 946**. Автономный вариант больше прежнего:
старый HTML встраивал шрифты, но требовал отдельных файлов диаграммы и лицензий.
Это изменение не удаляет прежние артефакты и пакеты.

Все 18 строк кандидата совпадают по хешу содержимого с соответствующей строкой базы.
Проверяется хеш имени общего CSS; для сравнения его содержимое подставляется в страницу.
Перед нормализацией CSS-ссылок проверяются точные байты обоих встроенных шрифтов.
Встроенные PNG и лицензии заменяются на прежние ссылки только при точном совпадении.
В PDF нормализуются лишь случайные префиксы шрифтов из шести букв и два XMP UUID.
Все остальные байты, включая Markdown, SVG, PNG и лицензии, сравниваются точно.

Первый запуск получает один тестовый текст на тип; следующие изменения снимка используют
кеш без генерации. Ссылки на общий CSS рантайма и применённых страниц ведут к существующим
файлам. Проверка в браузере **не подтверждена**: политика URL браузерного инструмента
запретила локальную страницу `file://`. Загрузка шрифтов браузером и визуальная приёмка
не входят в эти доказательства; другой маршрут открытия не использовался. Шрифты встроены
в общий CSS как data URL: внешние файлы шрифтов при `file://` могут блокироваться правилами
CORS браузера ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS/Errors/CORSRequestNotHttp)).

## Воспроизведение и проверки

Команды приведены в [английской версии](README.md#reproduce). Создавайте новые каталоги
вне репозитория. Для базы используйте архив указанного коммита без `-SourceRepository`,
для кандидата передайте путь к его дереву. `Save-Evidence.ps1` проверяет матрицу,
хеши содержимого, повторное использование текста и число общих ресурсов.

Первый красный тест — `Package_pages_share_font_files_and_apply_preserves_their_relative_links`:
в старом HTML обнаружено `data:font/ttf;base64,`. Проверяются смена режима без генерации,
ссылки прежних пакетов, старые метаданные, повреждение/отсутствие CSS, выход пути за
каталог ресурсов, отсутствие метаданных, ручные правки, вложенный junction, прерывание
сборки и сохранение прежнего документа при ошибке генерации.

Поле артефакта `Resources` необязательно для прежних автономных документов. Общий режим
требует один CSS с именем по хешу; apply проверяет его до записи в worktree.
Смена HTML-режима меняет только ключ оформления. При изменении встроенных ресурсов или
правил оформления требуется повысить версию renderer. Поля публичного JSON-отчёта прежние;
счётчики copied/unchanged теперь учитывают общие ресурсы по одному разу.
