# Проверка раскрытия перед открытием кода · 2026-10-21

[English version](2026-10-21-publication.md)

## Граница и результат

В проверенном снимке не осталось подтверждённых срабатываний на учётные данные.
Это ограниченная проверка раскрытия, а не гарантия безопасности любого публикуемого содержимого.

| Поверхность | Проверено |
| --- | --- |
| История Git по доступным refs | Сканер обработал 901 коммит с изменениями |
| Actions | 764 доступных архива журналов; 2 сохранённых артефакта |
| Issues и PR | 867 текстов; 140 комментариев; 629 списков ревью (тексты ревью не возвращены) |
| Релизы | 3 релиза; 12 файлов, 1 216 705 494 байт |
| Метаданные файлов релиза | 12/12 размеров и SHA-256 GitHub совпали со скачанными байтами |
| Упомянутые GitHub-вложения | В собранных текстах подходящих ссылок не найдено |

## Метод и классификация

До использования сканер проверили искусственным примером токена GitHub. Gitleaks 8.30.1
его пропустил; отрицательный результат этой версии отвергнут. Официальная версия 8.18.4,
проверенная по опубликованной контрольной сумме загрузки, обнаружила пример и использовалась
со скрытием значений. Этот старый набор правил ищет известные шаблоны и не является исчерпывающим.

Два срабатывания Git в исторических замерах были 64-символьными SHA-256 для
`LocalAi.Broker.Client.dll`, а не данными аутентификации. Это проверено по конкретной
исторической ревизии без публикации значений.

Расширенная проверка вне Git дала 51 совпадение общего правила ключей. Все относятся
к публичным полям `performed_via_github_app.client_id` приложений Codex Connector
и Dependabot. Точное совпадение идентификаторов проверено через анонимный GitHub Apps API.
Секреты, исходные журналы, контакты заявки и приватные файлы проверки здесь не публикуются.

Архивы распакованы с ограничением размеров и защитой от выхода из каталога, symlinks
и повторов имён. Загруженные и распакованные файлы не запускались. Удалённая история,
журналы и артефакты не удалялись при проверке.

## Ограничения и дальнейшие шаги

Поиск текстовых шаблонов не доказывает, что каждый бинарный файл декодирован или свободен
от секретов/персональных данных. Скрытая история редактирования/удалений, неупомянутые
вложения и данные после снимка не покрываются этим утверждением. Новые журналы CI и релизы
требуют отдельных проверок. Исходные локальные доказательства сохранены отдельно с ограниченными ACL.

Подпись остаётся в [#210](https://github.com/MrAliev/local-ai-toolkit/issues/210).
Проверки публикации и развёртывание отслеживаются отдельно в
[#872](https://github.com/MrAliev/local-ai-toolkit/issues/872).
