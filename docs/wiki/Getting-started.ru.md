# Первый репозиторий

[English version](Getting-started.md) · [Главная](Home.ru.md)

## 1 · Осознанная установка

Прочитайте [требования и порядок установки](../installing.ru.md). Скачайте актуальный релиз
проекта, проверьте по release notes и просмотрите выбор зависимостей и моделей.
Политика по умолчанию требует полного размещения выбранной модели в VRAM.

## 2 · Явное подключение

Используйте установленный launcher. Пошаговое руководство определяет помощник `lai`
и команды; не обращайтесь к модельному backend напрямую.

```powershell
lai localai repo status --root C:\work\myapp
lai localai sync --root C:\work\myapp
lai localai hooks install --root C:\work\myapp
```

Подключение репозитория добровольное. Подключённый репозиторий не обязательно готов:
проверьте этап и счётчики сборки. Не запускайте дублирующие сборки во время синхронизации.

По умолчанию синхронизируется указанное рабочее дерево; `--all-worktrees` явно добавляет
остальные. Оценка перед запуском учитывает весь запланированный объём, а текущий прогресс
описывает выполняемый проход. Если общее время завершения неизвестно, оно так и указывается.
Сохраните ID операции, показанный при запуске: команда
`lai localai sync cancel --root C:\work\myapp --operation <GUID>` отменяет именно эту
операцию. Тайм-аут клиента сам по себе не означает, что серверная операция остановилась.

## 3 · Актуальный контекст

После сохранения правок, merge или смены ветки обновляйте индекс рабочего дерева до поиска.
Установленные hooks помогают, но нельзя считать, что они есть во всех репозиториях.
В MCP используйте `index_status`, затем при необходимости `index_refresh`.
Точные параметры — в [руководстве CLI](../using-it-from-the-command-line.ru.md)
и установленном навыке LocalAI.
