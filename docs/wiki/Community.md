# Build with the community

[Русская версия](Community.ru.md) · [Home](Home.md)

| Contribution | What makes it useful |
| --- | --- |
| Bug report | Minimal reproduction, version, expected/actual behavior and redacted diagnostics |
| Documentation | Accurate behavior, paired English/Russian text and working links |
| Code | Focused PR, failing test first where relevant, full suite and current-head CI |
| Architecture | User problem, alternatives, migration and evidence |

Read [Contributing](../../CONTRIBUTING.md), [governance](../governance.md),
[community rules](../../CODE_OF_CONDUCT.md) and [support](../support.md).
The project uses MIT; dependencies and models retain their own licenses.
Do not attach private source code, whole logs or credentials to a public report.

There is no response-time SLA. Release and signing approval remain separate from PR merging.
