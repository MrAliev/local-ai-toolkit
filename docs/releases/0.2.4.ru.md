# Local AI 0.2.4

[English version](0.2.4.md)

## Изменения

- Уведомления после работы локальной модели оценивают экономию как полный вход операции минус весь контекст, возвращённый облачному агенту. CLI JSON использует ту же оценку, включая отрицательный результат и ноль; недостаток данных обозначается явно. Старые записи использования сохраняют прежний смысл. (#905)
- При запуске брокера Windows сохраняются границы аргументов. (#884)
- Разбор журналов компилятора восстанавливает некорректно оформленные перечни диагностик, сохраняя проверку исходных данных. (#864)
- Проверка обновлений поддерживает явно заданную аутентификацию для приватных релизов GitHub. (#863)
- Метаданные релиза GitHub обрабатываются отдельно для каждого обращения. (#903)
- Усилены проверки границ выполнения команд. (#894)

## Обновление

Выполните `lai localai update --wait` или используйте установщик из этого релиза. Перед активацией обновление проверяет подпись манифеста и целостность пакета. Менять выбранные модели не требуется.

Числа токенов — условная оценка облачного контекста, а не счёт провайдера или подтверждение качества ответа. При недостатке исходных данных или неудачной доставке экономия не выдумывается.
