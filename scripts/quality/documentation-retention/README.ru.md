# Проверка хранения документации

[English version](README.md)

В #623 добавлена управляемая очистка с объяснением решений, дополняющая общие ресурсы из #680. `localai docs prune --root <repository>` только показывает план; `--apply` пересчитывает и выполняет его под общей блокировкой с build, apply и pin. `--keep N` сохраняет как минимум N последних пакетов: по умолчанию 5, минимум 1, порядок определяется временем изменения манифеста, при равенстве — идентификатором.

Дополнительно защищены текущий пакет, явные закрепления, происхождение каждого применённого файла, незавершённое применение, latest, две корректные версии артефакта каждого типа и их общие ресурсы/сохранённый текст. Поэтому число сохранённых версий может превышать лимит. Перед открытием закрепите пакет командой `localai docs pin --root <repository> --package <32-hex-id>`, после закрытия снимите закрепление через unpin. Произвольные вкладки браузера и внешние читатели автоматически не обнаруживаются.

Незавершённая сборка и применённые файлы без согласованных сведений о происхождении защищают всю историю до завершения сборки или согласования через apply. Повреждённые метаданные защиты и reparse points вызывают отказ до удаления. Неизвестные записи сохраняются. При удалении собственный каталог сначала выводится из графа ссылок, затем его файлы удаляются по отдельности; следующий запуск может завершить прерванную очистку. Файлы в рабочем дереве не являются целями очистки.

## Воспроизведение

Запускайте из корня репозитория с .NET 10. Укажите новый отдельный каталог фикстуры: существующий каталог будет отклонён. Установленный runtime и модели не используются.

```powershell
dotnet run --project scripts/quality/documentation-retention/DocumentationRetentionProbe.csproj --configuration Release -- <new-fixture-directory> <result.json>
dotnet test --project tests/LocalAi.IntegrationTests/LocalAi.IntegrationTests.csproj --configuration Release -- --filter-class '*Documentation*'
dotnet test LocalAi.slnx --configuration Release --max-parallel-test-modules 1 --timeout 20m
```

Проверка создаёт восемь ревизий исходников для 1, 5 и 12 типов, воспроизводя корректный фиксированный ответ генератора. Ревизия 1 закрепляется, ревизия 2 применяется, сохраняются два последних пакета. «До» и «после» относятся к одному хранилищу непосредственно вокруг очистки. Проверяются хеши всех сохранённых и применённых файлов, ссылки необходимых пакетов на артефакты, точность учёта удалённых байтов и отсутствие изменений от просмотра плана. Повторная очистка должна освободить ноль байтов. Девятая ревизия с последующей очисткой должна сохранить прежнее количество пакетов, артефактов и текстовых записей. Отмена и конкуренция проверяются управляемыми событиями; требований к скорости машины нет.

## Сохранённый результат

[Планы и измерения](evidence/retention.json), [хеши исходников](evidence/source-hashes.json). Базовый коммит: `ca84edde34fa9fc3b1b43869a123c8c146f71c32`; хеши определяют проверенные файлы с нормализацией переводов строк к LF. Случайные идентификаторы и длительность в метаданных могут немного менять объём между запусками.

| Типов | До, байт | После, байт | Освобождено, байт | Сохранено пакетов | Артефактов / текстовых записей |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 3 387 048 | 2 416 833 | 970 215 | 4 | 4 / 4 |
| 5 | 11 082 877 | 6 271 316 | 4 811 561 | 4 | 20 / 20 |
| 12 | 24 583 647 | 13 033 194 | 11 550 453 | 4 | 48 / 48 |

Хеши всех сохранённых и применённых файлов не изменились. Четыре пакета остались, поскольку две защищённые старые версии дополняют две последние. После ревизии 9 их количество осталось прежним. Явные закрепления, разные применённые версии, новые типы и неполное старое состояние могут увеличивать объём: политика хранения не является жёсткой квотой в байтах.

Граница измерения — логические размеры файлов хранилища документации, включая метаданные и общий CSS. Размер выделенного места файловой системы, применённая копия в рабочем дереве, индексы, качество моделей и задержка не измеряются. Вызовов модели: **0**. Экономия облачных токенов: **неприменима**. Общие шрифты и автономный HTML проверены отдельно в [documentation-resources](../documentation-resources/README.ru.md); эта проверка не подтверждает визуальную приёмку в браузере.

Первоначальный тест просмотра плана CLI упал на базовом коде: код завершения 2 вместо ожидаемого 0. После реализации прошли все **136 тестов документации**, без ошибок и пропусков. Результат полного прогона указан в pull request.
