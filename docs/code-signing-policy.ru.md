# Политика подписи кода

[English version](code-signing-policy.md)

**Статус: подключение планируется; одобрение SignPath и сертификат Authenticode не заявляются.**

Программы Local AI для Windows предполагается подписывать через бесплатную подпись кода SignPath
Foundation для проектов с открытым исходным кодом. **Пока в заметках к релизу не сказано, что
он подписан, его установщик не подписан Authenticode.** Сегодня релиз защищает его манифест:
он подписан ECDSA P-256, и установщик принимает пакет, только если манифест сходится с ключом,
встроенным в установщик, а пакет — с манифестом. См.
[«Что делает установщик»](how-it-works.ru.md#что-делает-установщик).

## Указание авторства

После одобрения подписанные через этот сервис релизы будут содержать строку:

Free code signing provided by [SignPath.io](https://signpath.io), certificate by
[SignPath Foundation](https://signpath.org).

## Что подписывается

Только программы, собранные из исходного кода этого репозитория собственной сборкой релиза
проекта:

| Файл | Что это |
| --- | --- |
| `LocalAi.Installer.exe` | установщик; он же удаляет Local AI |
| `localai-launcher.exe` | постоянная точка входа, на которую зарегистрированы все клиенты |
| `localai.exe` | командная строка |
| `codesearch.exe` | командная строка поиска по коду |
| `codesearch-mcp.exe` | сервер MCP поиска по коду |
| `locallm-mcp.exe` | сервер MCP локальных моделей |
| `LocalAi.Broker.exe` | брокер перед Ollama |

Файлы, которые проект не собирает, его сертификатом не подписываются никогда. В том числе
сторонние библиотеки в пакете: `pdfium.dll`, `libSkiaSharp.dll` и `libHarfBuzzSharp.dll`.

## Правила

- Запрос на подпись утверждает вручную утверждающий, по одному релизу за раз.
- На подпись отправляется только сборка коммита из `main`, сделанная из исходного кода
  сборкой релиза. Ничто, собранное на машине разработчика, не отправляется.
- Каждый участник команды пользуется многофакторной аутентификацией в GitHub и в SignPath.
- О программе, подписанной в нарушение этой политики, сообщается SignPath, а релиз, в котором
  она вышла, отзывается.

Это требования к будущему процессу подписи, а не подтверждение завершённого подключения
или проверки MFA. [Публикация и подпись](publication.ru.md) описывает оставшиеся шаги:
заявку, доверенную сборку CI, реальную политику сертификата и проверки продления сертификата.
