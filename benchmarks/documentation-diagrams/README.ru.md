# Эксперимент с диаграммами документации

[English version](README.md)

Измерено 2026-09-14 на двадцати графах зависимостей чтения PDF, брокера и установщика
из коммита a75796e. `results.json` сохраняет ответы, имя модели, длительности из квитанций
и результат структурной проверки. Каждая модель вызвана один раз для каждого графа
через общий брокер, без подмены резервной моделью. Модели и политика размещения не менялись.

| Модель | Структурно корректно | Среднее выполнение | Суммарное ожидание |
|---|---:|---:|---:|
| qwen3.5:9b | 5 / 20 | 14.8 с | 100.8 с |
| gpt-oss:20b | 14 / 20 | 29.9 с | 96.2 с |

Это небольшая проверка соблюдения формата, а не качества изображения или прозы.
Проверка разбирает XML ограниченного размера с запретом DTD, отклоняет активное
содержимое и внешние ресурсы, требует все заданные узлы, точные подписи и направленные
связи. Многоугольники наконечников стрелок не считаются дополнительными связями.
Первая версия проверки считала их дважды; приведённые числа пересчитаны по сохранённым
ответам после исправления. Размеры шрифтов, наложения и расположение стрелок здесь
не измеряются. Рабочий рендерер заново строит раскладку проверенной топологии и использует
контуры символов из комплектных шрифтов; координаты модели и системные шрифты не определяют результат.

По результатам изменён первоначальный выбор: общий документ с обзором и диаграммой
сначала создаёт gpt-oss, затем допускается одна попытка исправления и резервный qwen.
Перевод использует существующий маршрут `PlainTranslation`. Три некорректных ответа
завершают обработку единицы ошибкой. Проверки синтаксиса и ссылок на факты не доказывают
правильность смысла текста.

Повторный запуск на настроенной установке Windows с обеими доступными моделями:

```powershell
dotnet build benchmarks/documentation-diagrams/DiagramBenchmark.csproj --configuration Release
./benchmarks/documentation-diagrams/Run.ps1 -OutputDirectory "$env:TEMP/documentation-diagrams-repeat"
```

Скрипт делает сорок вызовов моделей; выполнение может занять двадцать минут.
Выберите каталог результатов вне репозитория. Скрипт сохраняет запросы, ответы и квитанции;
отказ брокера останавливает прогон без изменения политики или подмены модели.

Предыдущий эксперимент с переопределением модели через маршрутизатор исключён:
такое переопределение допускает резервную модель и не позволяет сравнивать запрошенные модели.
