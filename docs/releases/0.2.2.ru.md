# Local AI 0.2.2

[English version](0.2.2.md)

Установщик теперь добавляет в инструкции Codex и Claude правило минимизации чтения файлов облачным агентом. Первое чтение и механический анализ следует поручать Local AI, передавая пути к файлам и краткую задачу, а затем использовать ограниченный по объёму результат без привычного повторного чтения исходников в облаке.

Прямое облачное чтение остаётся для необходимой проверки, разрешения неоднозначности и получения точных фрагментов для безопасной правки. Управляющие инструкции читаются напрямую. Если облачный агент уже прочитал или создал нужные данные, локальный вызов следует пропустить, когда ожидаемое сокращение оставшейся работы не покрывает затраты на запрос и ответ. Оценка токенов должна честно учитывать уже прочитанные и частично прочитанные источники.

Правило применяется при установке или повторном применении интеграции инструкций Codex или Claude. Обновление только исполняемых компонентов не переписывает инструкции клиентов. Пользовательские правила вне управляемого блока сохраняются.
