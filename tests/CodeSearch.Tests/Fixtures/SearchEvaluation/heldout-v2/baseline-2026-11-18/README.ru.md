# Первое парное измерение

[English version](README.md)

Baseline и candidate вернули одинаковые нормализованные последовательности результатов
для всех **60 запросов** к трём репозиториям исходников. Ранжирование, выбор модели и порог
`0.43` не менялись. Это подтверждает совпадение поведения измерительного стенда, а не улучшение качества.

| Язык исходников | Строгая recall@10 | Намерения с ответом: успешны обе формулировки | Ложные срабатывания на запросах без ответа | Намерения без ответа: есть хотя бы один результат |
| --- | ---: | ---: | ---: | ---: |
| C# | 100% | 5/5 | 10/10 | 5/5 |
| TypeScript | 0% | 0/5 | 10/10 | 5/5 |
| Python | 100% | 5/5 | 9/10 | 5/5 |

Основные групповые показатели: обе формулировки успешны для 10/15 намерений с ответом;
хотя бы один результат есть для 15/15 намерений без ответа. Описательные 95% интервалы Уилсона:
41,7–84,8% и 79,6–100% соответственно. Синтетические шаблоны связаны между собой, поэтому
допущение независимости используется для справки и не гарантирует качество на других данных.
Метод интервала описан у [NIST](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm).

Строгая оценка символов TypeScript остаётся нулевой. Отдельная **диагностическая проверка после
измерений** нашла нужный путь в top‑10 для всех десяти положительных запросов, но возвращённые
чанки названы именами файлов вместо размеченных объявлений `format`/`validate`. Этот подсчёт
путей не заменяет исходную метрику и не меняет разметку. Представление символов и чанков требует
отдельного разбора. Результат для запроса без прямой реализации считается операционным ложным
срабатыванием; это не оценка галлюцинаций и не обнаруженная уязвимость.

Эталоны подготовлены с помощью ИИ и до измерений проверены независимым агентом без показа разметки
и поисковых результатов. Проверка человеком и новизна относительно обучающих данных модели не
подтверждены. Теперь это известный регрессионный корпус. Исторические оценки v1 получены на других данных.

Исходники baseline: `86a54e04c3e77a94f41e63dc4834dfe73639edf6`. Измеренный candidate:
`98366969b05d4ae42508520723aba5e219e3fcca`, сохранённый в локальном приватном Git bundle.
Его неканоническое представление даты исключено из публикуемой истории; последующие изменения
затрагивают offline-проверку, тесты и отчёты, а не реализацию поиска. Обе CLI запускались из
отдельных копий с зафиксированными хешами. Использовались те же три поколения исходников и индексов.

Первое offline-сравнение отклонило различное представление даты калибровки профиля. Во всех шести
записях совпадают момент времени и остальные поля профиля. Проверка исправлена: только это поле
сравнивается по моменту времени после проверки ISO-формата с явным смещением. Неверная,
отсутствующая или обозначающая другой момент дата по-прежнему вызывает отказ. Синтетические
тесты прошли; сохранённые результаты сравнены повторно **без новых поисковых запросов**.
Исходные приватные байты протокола и artifact plan, а также неудачное сравнение сохранены.
Публичный протокол явно помечен как каноническая копия после измерений, а не первоначальный
зафиксированный файл. Старый и новый хеши связаны в [summary.json](summary.json).

Запрошенный и установленный тег модели — `qwen3-embedding:8b-q8_0`. Хеш весов и подтверждение
маршрутизации каждого запроса недоступны. Usage notices для candidate сообщают, что модель не
вызывалась. Общая нагрузка, кеширование и состояние прогрева не контролировались, поэтому
длительности только описывают запуск; время ожидания очереди неизвестно. Импорт TypeScript/Python
завершился успешно. C# выдал диагностическое сообщение Roslyn о Git snapshot; проверено одно
точное определение, а не полная работоспособность навигации.

[Архив доказательств](evidence.zip) содержит точные ответы оценивания, исходный план хешей сборок,
отчёт сравнения, помеченную публичную копию протокола и производные сведения о хешах CLI.
В него не входят приватный исходный протокол, полные runtime-записи, каталоги профиля пользователя и локальные
представления дат. Это не полный пакет для независимого воспроизведения provenance.
[Манифест SHA-256](evidence.sha256).
