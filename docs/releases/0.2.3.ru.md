# Local AI 0.2.3

[English version](0.2.3.md)

Это корректирующий выпуск с улучшениями общих обновлений, проверки журналов компиляции и объяснения оценки экономии токенов.

## Изменения

- Перед активацией обновления брокер дожидается завершения текущих задач и приостанавливает приём новых. Обновление из CLI передаётся лаунчеру после выхода вызывающего процесса, чтобы собственная блокировка версии не мешала обновлению.
- Клиент восстанавливает работу, если брокер перезапустился во время ожидания задачи в очереди или её выполнения.
- Отчёты о журналах компиляции опираются на детерминированные данные исходного файла: число строк диагностики, количество по каждому коду, расположение и хеш источника. Повторяющиеся диагностики в самом журнале учитываются; перекрывающиеся фрагменты не увеличивают счётчик. Несогласованные с источником утверждения модели отклоняются, а итоговые счётчики MSBuild показываются отдельно.
- Оценка токенов сравнивает текст, видимый облачному клиенту, с предполагаемой альтернативной работой, вместо подсчёта всего транспортного конверта MCP. Это приблизительное сравнение, а не измерение расходов у облачного провайдера.
- Операции с эталонными файлами документации отклоняют символические ссылки, junction и другие reparse points до чтения или записи. В стандартной сборке также обновлена зависимость System.Security.Cryptography.Pkcs до исправленной версии 8.0.2.
- Русская и английская документация уточняет границу между локальной и облачной обработкой, хранение данных и установку опубликованных выпусков. Улучшены очистка тестовых каталогов Windows и диагностика сбоев проверок SCIP.

## Обновление

Скачайте `LocalAi.Installer.exe` из выпуска на GitHub. Для автономной установки держите вместе установщик, `localai-package.zip`, `release-manifest.json` и `release-manifest.sig` одной версии.

Используется прежний доверенный ключ подписи манифеста. Смена ключа и принудительная переиндексация не требуются. Другие проекты и сессии могут продолжать использовать общую среду выполнения; перед переключением версии активация дожидается текущих задач.

## Проверка

Перед подготовкой выпуска сборка Release завершилась без предупреждений и ошибок. Полный локальный набор: 5937 тестов, 5920 успешно, 17 пропущено, ошибок нет. Локальные пропуски связаны с окружением проверок SCIP и символических ссылок; GitHub workflow также проверяет коммит выпуска в среде CI.

Утилита выпуска требует успешный workflow Build and test для точного коммита релиза, затем собирает, подписывает и проверяет пакет перед публикацией четырёх файлов. Манифест подписан ECDSA P-256; этот выпуск не заявляет подпись установщика Windows Authenticode.

Для нерегулярного сбоя проверки SCIP с лимитом в пять секунд из [#843](https://github.com/MrAliev/local-ai-toolkit/issues/843) добавлены диагностика и независимые проверки каждого инструмента. Причина прежнего сбоя пока не установлена; выпуск не заявляет об устранении его первопричины.
