## Обновить

```powershell
lai localai update
```

Скачивает релиз, **проверяет его подпись**, ставит новый каталог версии и переключает на него
launcher. Пути, прописанные клиентам, не меняются — они указывают на launcher, а не на
версию. Пока у брокера есть ожидающие или выполняющиеся задания, команда отказывает;
`--wait` ждёт завершения обоих видов заданий (до 30 минут), а `--force` ставит самый новый релиз,
даже если он не новее установленного. Скачивание и проверка пакета не мешают другим сессиям.
На время завершающего ожидания и активации приём новых заданий приостанавливается; повторите
такие вызовы после обновления. При ошибке или отмене обычный приём заданий восстанавливается.
Launcher запускает временную копию обновляющего процесса вне установленной версии, поэтому
переключение версий не ждёт завершения самого обновления. Команда продолжает показывать
прогресс и возвращает итоговый результат; временная копия удаляется после выхода процесса.
Старый launcher без этой передачи управления не сможет обновить сам себя таким способом:
первый переход выполните установщиком из опубликованного релиза GitHub. Для последующих
обновлений можно использовать `localai update`.

Проверка обновлений по умолчанию **выключена**, поэтому сама установка за новыми версиями не
ходит. Включить и настроить частоту:

```powershell
lai localai policy set --update-check on
lai localai policy set --update-check-interval-hours 24
```

Пока опубликованных релизов нет, `update` находить нечего — обновление сейчас идёт тем же
путём, что и установка: собрать пакет и запустить установщик поверх.

## Убрать индекс, но оставить продукт

```powershell
lai localai prune            # снести устаревшие поколения, overlay, архив очереди, старую телеметрию и прежние версии
lai localai prune --dry-run  # сначала посмотреть, что именно уйдёт
```

`prune` также удаляет запись репозитория, чей каталог Git исчез, и запись, которая так и не
опубликовала поколение и не обновлялась дольше срока хранения архива. У удалённого worktree
убираются только его overlay, а если том недоступен, запись не трогается.

## Удалить целиком

Local AI регистрируется в **«Приложения и возможности»** как `Local AI Toolkit` —
удаление оттуда, как у любой программы. Запустится мастер, и решение принимается **по каждой
части отдельно**, а не одним «да»:

| Часть | Что это |
| --- | --- |
| Бинарники, launcher, указатель версии | собственно удаление продукта |
| Индексы репозиториев и их overlay | часы работы видеокарты и хранящиеся вместе с ними пакеты документации; сносить их стоит, только если уходите совсем |
| Настройки рантайма | политика размещения, обновления, языковые серверы — то, что переустановка иначе бы учла |
| Очередь, архив, карантин, телеметрия | временное состояние брокера; сохранять нечего |
| Всё остальное в корне рантайма | всё, чего установщик не распознаёт, перечислено по путям |
| Хуки Git | по каждому подключённому репозиторию |
| Интеграция с Claude и с Codex | отдельно для каждого: снять регистрацию MCP-серверов и убрать блок инструкций |
| Ключи подписи релизов | **спрашивается всегда** — по умолчанию не удаляются ни при одном варианте |

Есть готовые наборы: убрать всё, кроме ключей подписи; убрать бинарники, временное состояние
и всё нераспознанное, оставив индексы и настройки; убрать Local AI из Claude, Codex и
Git-хуков, не трогая рантайм. Набор — это просто заранее расставленные галочки, и
любую из них можно переставить.

**Модели остаются.** Они принадлежат Ollama, а не Local AI, и могут быть нужны Вам для
другого. Удалять их — через саму Ollama.

**Запись об установке тоже остаётся** — намеренно, вне каталога рантайма. Это журнал того,
что установки сделали с машиной.
