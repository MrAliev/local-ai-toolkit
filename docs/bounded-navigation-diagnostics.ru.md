# Проверка отдельного запроса навигации

[Оглавление](README.ru.md#оглавление) · [English version](bounded-navigation-diagnostics.md)

По умолчанию MCP-инструмент `index_status` выполняет быструю проверку заголовков. `HeaderOnly` не подтверждает целостность всех данных, полноту покрытия языков или готовность каждого запроса навигации. Для проверки одного запроса укажите `navigationPath`, номер строки `navigationLine` с единицы, столбец `navigationColumn` в единицах UTF-16 с единицы и операцию `navigationOperation` (`definition` либо `references`). Например:

```json
{"root":"R:/example","navigationPath":"src/Example.cs","navigationLine":42,"navigationColumn":1,"navigationOperation":"references"}
```

Дополнительный JSON внутри границы untrusted-content содержит `HeaderEvidence`, `Freshness`, язык, позицию, операцию, `Precision`, `ResultCount` и `Reason`. Значение `Coverage` остаётся `Unknown`: ни читаемые заголовки, ни найденная позиция не доказывают полноту покрытия документа или языка. Проверка выполняет не более одной существующей операции навигации, без пересборки индекса, обхода репозитория или постоянного кэша проверок. Её нельзя совмещать с `runtimeEvidenceOnly`.

Актуальность индекса и точность ответа — отдельные характеристики. Отстающий индекс может ответить на конкретный запрос, а актуальный заголовок не гарантирует точного ответа. Если семантический индекс не вернул точных ссылок, возможен переход к ограниченным текстовым совпадениям с явной отметкой деградации и эвристической точности. Это означает отсутствие записанных точных ссылок в ответе на данный запрос, а не отсутствие символа или всех его использований в репозитории. При нулевом результате `Precision` остаётся `Unknown`; глобальное отсутствие использований не считается доказанным.
