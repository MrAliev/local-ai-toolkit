# Доверие, конфиденциальность и подпись

[English version](Trust-and-security.md) · [Главная](Home.ru.md)

| Уровень | Текущая граница |
| --- | --- |
| Локальные вычисления | Брокер использует настроенный backend; клиент может передать ответы дальше |
| Целостность пакета | ECDSA-подпись манифеста и хеш пакета |
| Подтверждение артефактов релиза | Фиксирует байты опубликованных файлов; само по себе не доказывает сборку из заявленного исходного кода |
| Издатель Windows | Подключение SignPath остаётся планом в [#210](https://github.com/MrAliev/local-ai-toolkit/issues/210); наличие сертификата издателя здесь не подтверждается |

```mermaid
  source["Проверенный код"] --> build["Доверенная сборка CI"]
  build --> approval["Ручное одобрение подписи"]
  approval --> own["Подпись собственных PE"]
  own --> package["Итоговый ZIP"]
  package --> manifest["Хеш и подпись манифеста"]
  manifest --> verify["Проверка и публикация"]
```

Это **целевой маршрут подписи**, а не доказательство существования подписанного релиза.
Не подписывайте чужие DLL как собственный код. Не меняйте пакет после вычисления
хеша и подписи манифеста.
