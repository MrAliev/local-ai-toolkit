# Local AI 0.2.2

[English version](0.2.2.md)

Установщик теперь добавляет обоим поддерживаемым клиентам правило минимизации чтения файлов облачным агентом. Первое чтение и механический анализ следует поручать Local AI, передавая пути к файлам и краткую задачу, а затем использовать ограниченный по объёму результат без привычного повторного чтения исходников в облаке.

Прямое облачное чтение остаётся для необходимой проверки, разрешения неоднозначности и получения точных фрагментов для безопасной правки. Управляющие инструкции читаются напрямую. Если облачный агент уже прочитал или создал нужные данные, локальный вызов следует пропустить, когда ожидаемое сокращение оставшейся работы не покрывает затраты на запрос и ответ. Оценка токенов должна честно учитывать уже прочитанные и частично прочитанные источники.

Установщик добавляет правило при настройке или повторной настройке интеграции с клиентом. При обновлении только исполняемых компонентов инструкции клиентов сохраняются. Пользовательские правила вне управляемого блока сохраняются.
